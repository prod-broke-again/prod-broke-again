# Евгений · full-stack разработчик

Laravel, Vue, Flutter и Ionic. Делаю бэкенд с админкой, веб-интерфейсы и мобильные клиенты, подключаю ИИ и мессенджеры. Открыт для проектной работы.

## Как работаю

Разрабатываю в связке с ИИ-агентами: Claude Code, Cursor, Antigravity. Пишу инструкции и правила для агентов, собираю собственные MCP-серверы под рабочие инструменты. Отвечаю за архитектуру, постановку задач и проверку результата.

## Стек

- **Бэкенд:** PHP 8, Laravel, Filament, Sanctum, очереди, Reverb, REST API
- **Фронтенд:** Vue 3, Inertia, TypeScript, Pinia
- **Мобильная разработка:** Flutter, Ionic + Capacitor, Electron
- **Интеграции:** боты Telegram и VK, внешние HTTP API, ИИ-провайдеры, MCP
- **Инфраструктура:** Docker, GitHub Actions, PostgreSQL, MySQL, Redis
